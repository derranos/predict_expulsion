# Прогноз риска отчисления студентов

Проект использует OULAD (набор данных об обучении в Открытом университете), чтобы оценить риск неуспешного завершения курса по информации за первые 28 дней.

## Цель

Релизовать модели: MLP, GRU и их гибридную версию версию.

Сравнить результаты моделей с опубликованным исследованием на OULAD. Модель определяет, завершится ли обучение неуспешно: студент не сдаст курс (`Fail`) или отчислится (`Withdrawn`). В набор входят студенты, которые оставались на курсе на 28-й день.

## Как запустить

Нужен Python 3.12. Сначала установите зависимости из корневой папки проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Поместите исходные файлы OULAD в `data/raw_data`. Затем из корневой папки выполните команды по порядку:

```powershell
python data/data_processing_MLP.py
python data/data_grouping.py
python mlp/learning/train.py
```

Первый скрипт готовит признаки за первые 28 дней. Второй делит данные на обучающую, проверочную и тестовую части, не разделяя записи одного студента между ними, и приводит числовые признаки к сопоставимому масштабу. Последний подбирает настройки и обучает MLP.

Для ускорения обучения можно использовать видеокарту NVIDIA с поддержкой CUDA. Без неё обучение запустится на процессоре.

## Что уже сделано

- Подготовлены признаки по характеристикам студентов, ранним оценкам и кликам в учебной системе.
- Данные разделяются по студентам; параметры масштабирования вычисляются только по обучающей части.
- Настройки MLP подбираются с помощью Optuna (библиотеки для автоматического подбора настроек). Обучение останавливается, если проверочная ошибка перестаёт улучшаться.
- Модель и отчёт с метриками сохраняются в `mlp/learning`.

Пока обучается только MLP. Клики за первые 28 дней суммируются по шести категориям. 

## Последний результат MLP

| Показатель | Результат |
|---|---:|
| Точность на тестовой части | 0,7132 |
| ROC-AUC | 0,7798 |
| Recall@Top20% | 0,3712 |
| Ошибка на тестовой части | 0,5568 |

Лучшие найденные настройки: 2 скрытых слоя по 256 нейронов, Dropout = 0,5, скорость обучения 0,0001, пакет из 32 примеров. Проверочная ошибка составила 0,5451.

В статье для исхода `Fail` или `Withdrawn` указаны ROC-AUC 0,7747 и Recall@Top20% 0,3720. Результаты MLP близки к этим значениям. Прямое сравнение ограничено различиями в признаках и разбиении данных. [Статья](https://www.frontiersin.org/journals/education/articles/10.3389/feduc.2026.1917092/full).
